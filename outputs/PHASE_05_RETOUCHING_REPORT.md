## Case-study decisions

### CASE A — Background Cleanup

- **Problem:** Small surface distractions in a product-detail background must be reduced without erasing real wool character.
- **Decision:** Clean only genuine contaminants; retain irregular texture as product evidence.
- **AI Operation:** Narrow cleanup around a locked four-hole button.
- **Manual/QC Decision:** Button geometry, color, thread, fabric color and texture all pass.
- **Final Result:** `PASS`; suitable for the later case study.

### CASE B — Composition / Canvas Extension

- **Problem:** Square macro limits portrait-channel layout flexibility.
- **Decision:** Extend only outside the source composition; keep central fold as authenticity anchor.
- **AI Operation:** 4:5 vertical textile outpainting with locked color, fiber scale, fold and light direction.
- **Manual/QC Decision:** Visual continuity passes; synthesized zones are explicitly limited to layout context.
- **Final Result:** `PASS`; suitable for the later case study.

### CASE C — Minor Visual Correction

- **Problem:** Source model image contains unsupported patch-pocket outlines despite correct three-button closure.
- **Decision:** Remove only erroneous seam lines; no global regeneration or beauty retouching.
- **AI Operation:** Four tightly scoped edit attempts, including full-reference and reduced-reference retries on 2026-09-21.
- **Manual/QC Decision:** All attempts failed before returning an image. No unverifiable result may be accepted.
- **Final Result:** `UNCERTAIN / NOT PRODUCED`; useful in the case study as an AI/human boundary example, not as a visual final.
