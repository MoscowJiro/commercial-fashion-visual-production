# CASE A — Background Cleanup

## Problem

The approved button macro contains natural wool variation plus small, potentially distracting surface specks. Cleanup must not flatten the authentic fiber texture or redraw the button.

## Decision

Use a narrowly scoped AI cleanup on the fabric surrounding the button only. Preserve the button and all product-defining detail exactly.

## AI Operation

- Remove isolated loose lint, tiny distracting specks, and accidental dirty-gray micro-discoloration only.
- Lock button position, scale, circular outline, brown marbling, four holes, attachment thread, shadow, crop, and camera angle.
- Lock cream/ivory color, fiber density, nubby texture, and natural tonal variation.

## Manual / QC Decision

- Button geometry: PASS
- Four-hole count: PASS
- Button color/material appearance: PASS
- Fabric color: PASS
- Fabric texture retention: PASS
- Unsupported additions: none observed

## Final Result

**PASS.** AFTER is approved as a restrained background/surface cleanup demonstration.
